\section{Условие задачи}

\subsection{Цель работы}

Написать одну законченную консольную программу на языке C++, содержащую определение класса многочлена. Класс должен соответствовать правилам ООП, обеспечивать корректное управление динамической памятью, реализовывать необходимые методы и поддерживать базовые операции.

\subsection{Вариант 14}

Многочлен n-й степени с массивом коэффициентов A[0]..A[n]. Необходимо реализовать:

\begin{itemize}
  \item Конструктор по умолчанию
  \item Конструктор копирования
  \item Конструктор перемещения
  \item Деструктор
  \item Оператор присваивания с реализацией через копию (copy-and-swap idiom)
  \item \texttt{void print(std::ostream\& os) const} — вывод многочлена в поток
  \item \texttt{double evaluate(double in) const} — вычисление значения многочлена в точке
  \item \texttt{void evaluate\_many(const double* xs, double* ys, size\_t n) const} — вычисление значений для массива точек
  \item \texttt{void add(const Polynomial\& other)} — сложение с другим многочленом (in-place)
  \item \texttt{void mul(const Polynomial\& other)} — умножение на другой многочлен (in-place)
\end{itemize}

\subsection{Требования к реализации}

\begin{itemize}
  \item Хранение коэффициентов — динамический массив \texttt{double*} по степеням (A[0] — свободный член, A[i] — коэффициент при $x^i$)
  \item При наличии старших нулевых коэффициентов они должны отбрасываться (метод \texttt{trim})
  \item Корректная работа с пустым многочленом (нулевая степень или все коэффициенты нулевые)
  \item Глубокое копирование и перемещение с корректным владением памятью
  \item Отсутствие утечек памяти
  \item Проект CMake и не менее 10 тестов Google Test
\end{itemize}
