\section{Выводы}

В ходе выполнения лабораторной работы №2 реализован класс \texttt{Polynomial} для работы с многочленами с хранением коэффициентов в динамическом массиве. Применены RAII, глубокое копирование, перемещение, идиома copy-and-swap. Реализованы методы \texttt{print}, \texttt{evaluate}, \texttt{evaluate\_many}, \texttt{add}, \texttt{mul}. Корректно обрабатываются случаи пустого многочлена и старших нулевых коэффициентов (\texttt{trim}). Проект оформлен через CMake, покрыт тестами Google Test (27 тестов). Достигнута требуемая функциональность без использования запрещённых средств.
