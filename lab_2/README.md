# Лабораторная работа 2 — Классы

**Вариант 14**

## Задача

Написать консольную программу с классом `Polynomial`, который хранит многочлен через динамический массив `double*` коэффициентов по степеням. Вся логика (конструкторы, деструктор, присваивание, методы) реализована вручную с управлением памятью через `new[]`/`delete[]`.

Реализовать конструкторы (по умолчанию, копирования, перемещения), деструктор, оператор присваивания с реализацией через копию, методы: `print(ostream&)`, `evaluate(x)`, `evaluate_many(xs, ys, n)`, `add(const Polynomial&)`, `mul(const Polynomial&)`. При хранении старшие нулевые коэффициенты отбрасывать (trim). Правильная работа с пустым многочленом.

## Что реализовано

- `polynomial.h` / `polynomial.cpp` — класс `Polynomial` с RAII, правилами трёх/пяти (копирующий конструктор, перемещающий конструктор, копирующий оператор присваивания через copy-and-swap), `trim()`, `swap()`
- `main.cpp` — демонстрационный пример работы
- `tests/test_polynomial.cpp` — **27 тестов** Google Test
- `docs/report` — отчёт по лабораторной работе на XeLaTeX

## Ограничения

- Управление памятью только вручную (`new[]` / `delete[]`)
- Без классов/конструкций, не оговорённых заданием (в рамках данной работы используются только ручные средства работы с памятью)
- C++20, CMake 3.16+, Google Test 1.14.0
