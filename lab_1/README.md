# Лабораторная работа 1 — Основы C++

**Вариант 2 · семейство A — линейный динамический массив**

## Задача

Написать консольную программу — интерактивный справочник над динамическим
массивом `int*` с текстовым меню. Вся логика выносится в библиотеку чистых
функций: они не вводят и не выводят данные сами, а принимают их параметрами
(указателями, ссылками, out-параметрами) и возвращают результат.

**Алгоритм варианта:** сортировка выбором по возрастанию, затем разворот
массива на месте двумя указателями. Контрольный пример:

```
{3, 1, 4, 1, 5}  →  {1, 1, 3, 4, 5}  →  {5, 4, 3, 1, 1}
```

**Обязательные операции:** создание, освобождение, изменение размера, вставка,
удаление, печать. Плюс бинарный поиск с возвратом найденного индекса через
out-параметр.

**Ограничения:** запрещены классы, конструкторы, семантика копирования и
перемещения, `std::string`, `std::vector`, `std::array` и умные указатели.
Память — только вручную (`new[]` / `delete[]`).

**Часть 2:** проект CMake и не менее 10 тестов Google Test.

## Что реализовано

- `array_ops.h` / `array_ops.cpp` — 10 чистых функций над `int*`, включая
  `array_selection_sort`, `array_reverse` и `array_binary_search`.
- `main.cpp` — меню из 9 пунктов, проверка ввода через `std::cin`, штатная
  обработка конца ввода, перехват `std::bad_alloc` без потери исходных данных,
  освобождение памяти с обнулением указателя.
- `tests/test_variant.cpp` — **26 тестов** в трёх наборах (`ArrayOps`,
  `Variant2`, `BinarySearch`), подключены к CTest.
- `docs/report` — отчёт по лабораторной работе на XeLaTeX.
