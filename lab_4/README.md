# Лабораторная 4, вариант 19

База `BankProduct` и классы `Deposit`, `Credit`, `Card` находятся в отдельных
парах `.h` / `.cpp`. Общие параметры проверки вынесены в `params.h`.
В `main.cpp` приведён небольшой пример продуктов и коллекции.

## Коллекция

`BankCollection` (`bank_collection.h/.cpp`) владеет собственным динамическим
массивом `BankProduct*` и всеми продуктами в нём. `add(const BankProduct&)`
сохраняет независимую копию через виртуальный `clone()`, исходный объект
остаётся у вызывающего кода. Не нужно писать `add(new Deposit(...))`:
используйте `add(Deposit(...))` либо передайте существующий объект по ссылке.

Копирующий конструктор выполняет глубокое копирование. Перемещающий
конструктор передаёт владение и оставляет источник пустым.
`operator=(BankCollection other)` принимает аргумент по значению и использует
copy-and-swap: обслуживает и копирующее, и перемещающее присваивание.
Если копирование бросит исключение, исходная и целевая коллекции сохраняются.
`swap()` и перемещающий конструктор помечены `noexcept`.

- `size()`, `empty()` и `operator[]` позволяют обходить продукты по индексам.
  Неверный индекс вызывает `std::out_of_range`; const-коллекция возвращает
  const-ссылки на продукты.
- `erase(index)` удаляет продукт и сдвигает оставшиеся; `clear()` удаляет все.
- `total_metric()` возвращает сумму метрик, для пустой коллекции - 0.
- `max_product()` ищет максимум за один проход, возвращает первый при равенстве
  метрик, а для пустой коллекции - `nullptr`.

## Формат ввода и вывода

Ввод содержит только значения полей без имени класса:

- `Deposit`: `sum rate years cumulative`, например `1000 0.1 2 1`.
- `Credit`: `sum rate years annuity`, например `120000 12 1 1`.
- `Card`: `spending rate`, например `10000 0.02`.

Вывод содержит имя класса и подписи полей:

```text
Deposit: sum=1000 rate=0.1 years=2 cumulative=1
Credit: sum=120000 rate=12 years=1 annuity=1
Card: spending=10000 rate=0.02
```

Флаги принимают только 0 или 1. Метрика выводится приложением отдельно.
Ошибки чтения устанавливают `failbit` и сохраняют прежнее состояние объекта.
Сумма, ставка и расходы должны быть конечными и неотрицательными;
срок задаётся целым числом лет, строго больше нуля.
Некорректные параметры конструктора вызывают `std::invalid_argument`.

## Формулы

Формулы реализованы буквально по ТЗ:

- Вклад: `sum * rate` либо `sum * ((1 + rate)^years - 1) / years`.
- Кредит без аннуитета: `sum * rate`.
- Аннуитетный кредит: `12 * A`, где `r = rate / 1200`, `n = years * 12`,
  `A = sum * r / (1 - (1 + r)^(-n))`.
  Для аннуитетного кредита ставка должна быть строго больше нуля.
- Карта: `spending * rate`.
  `hasCashback()` возвращает `rate > 0`.
