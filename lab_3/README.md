# Лабораторная работа 3 — Множество объектов

**Вариант 19 — ExamGrade: id студента и оценка.**

`ExamGradeSet` хранит динамический массив без сортировки, не более одной оценки на студента. `add` добавляет запись или заменяет оценку по id; возвращает `false`, если запись не изменилась.

Реализованы правило пяти, копирующее присваивание через copy-and-swap, поиск, удаление, операторы принадлежности, объединения, пересечения, разности, сравнения и вывода. Память выделяется вручную, capacity удваивается, удаление сохраняет порядок.

`contains` и `remove` работают по id. Равенство учитывает также оценки. В объединении при совпадении id берётся оценка справа, в пересечении — слева.

- `src/` — классы и демонстрационный пример.
- `tests/` — 19 тестов Google Test.
- `docs/report/` — отчёт и исходники XeLaTeX.

Сборка и запуск описаны в [run.md](run.md).
